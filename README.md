# SVV Lab Task 3: Autonomous Delivery Robot

This repository contains the software verification and validation lab artifacts for the Autonomous Delivery Robot scenario. The project focuses on extracting requirements, defining system states, and creating a state transition table for an autonomous package delivery system to ensure correct operational behavior.
